# 🪟 Запуск на Windows - Самый простой способ

## ✅ Что нужно установить

### 1. Python (обязательно!)
1. Скачайте: https://www.python.org/downloads/
2. Запустите установщик
3. ⚠️ **ВАЖНО: Поставьте галочку "Add Python to PATH"**
4. Нажмите "Install Now"
5. Дождитесь окончания установки

### 2. Node.js (обязательно!)
1. Скачайте: https://nodejs.org/ (версию LTS)
2. Запустите установщик
3. Нажимайте "Next" со всеми настройками по умолчанию
4. Дождитесь окончания установки

### 3. Перезагрузите компьютер после установки!

---

## 🚀 ЗАПУСК ПРИЛОЖЕНИЯ - 2 простых клика!

### Вариант 1: Используйте готовые bat-файлы (РЕКОМЕНДУЕТСЯ)

#### Шаг 1: Запустите Backend
1. Откройте папку `C:\Users\kaire\bppk-system\backend`
2. **Двойной клик** по файлу `start_backend.bat`
3. Дождитесь появления сообщения: `Uvicorn running on http://0.0.0.0:8000`
4. **НЕ ЗАКРЫВАЙТЕ это окно!**

#### Шаг 2: Запустите Frontend
1. Откройте папку `C:\Users\kaire\bppk-system\frontend`
2. **Двойной клик** по файлу `start_frontend.bat`
3. Дождитесь появления: `Local: http://localhost:3000/`
4. **НЕ ЗАКРЫВАЙТЕ это окно!**

#### Шаг 3: Откройте браузер
- Перейдите на: **http://localhost:3000**

🎉 **Готово!** Используйте тестовые аккаунты для входа (см. ниже)

---

### Вариант 2: Запуск через командную строку

#### Шаг 1: Откройте командную строку
- Нажмите `Win + R`
- Введите `cmd`
- Нажмите Enter

#### Шаг 2: Запустите Backend
```bash
cd C:\Users\kaire\bppk-system\backend
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python init_db.py
python -m uvicorn app.main:app --reload
```

Должно появиться:
```
Default admin created: admin@bppk.ru / admin123
...
Uvicorn running on http://127.0.0.1:8000
```

✅ **Не закрывайте это окно!**

#### Шаг 3: Откройте НОВУЮ командную строку (Win+R → cmd)
```bash
cd C:\Users\kaire\bppk-system\frontend
npm install
npm run dev
```

Должно появиться:
```
Local: http://localhost:3000/
```

#### Шаг 4: Откройте браузер
```
http://localhost:3000
```

## ❌ Решение проблем

### Проблема 1: "Python is not recognized"
**Решение:**
1. Переустановите Python
2. **ОБЯЗАТЕЛЬНО** поставьте галочку "Add Python to PATH"
3. Перезагрузите компьютер

### Проблема 2: "npm is not recognized"
**Решение:**
1. Переустановите Node.js с https://nodejs.org/
2. Перезагрузите компьютер

### Проблема 3: Порт уже занят (Port 8000/3000 is already in use)
**Решение:**
1. Закройте все окна командной строки
2. Откройте Диспетчер задач (Ctrl+Shift+Esc)
3. Найдите процессы `python.exe` и `node.exe`
4. Завершите их
5. Запустите приложение заново

### Проблема 4: "Fatal error in launcher" или "Unable to create process"
**Решение:**
Используйте готовые bat-файлы! Они обходят эту проблему.

Или выполните:
```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### Проблема 5: Frontend не видит Backend
**Решение:**
1. Убедитесь, что Backend запущен и работает
2. Откройте http://localhost:8000/docs в браузере
3. Если открывается - всё хорошо, перезапустите Frontend
4. Если не открывается - перезапустите Backend

### Проблема 6: Ошибка при установке зависимостей
**Решение:**
```bash
python -m pip install --upgrade pip setuptools wheel
python -m pip install -r requirements.txt
```
