# БППК - Система тестирования и экзаменов

Веб-приложение для проведения тестирования и экзаменов в БППК (Барнаульский Промышленно-Педагогический Колледж).

## Технологии

### Backend
- **FastAPI** - современный веб-фреймворк для Python
- **PostgreSQL** - надежная реляционная база данных
- **SQLAlchemy** - ORM для работы с БД
- **JWT** - аутентификация через токены
- **Pydantic** - валидация данных

### Frontend
- **React** - библиотека для создания пользовательских интерфейсов
- **React Router** - маршрутизация
- **Axios** - HTTP клиент для API запросов
- **Vite** - быстрая сборка проекта

## Функционал

### Роли пользователей

#### 1. Администратор
- Управление пользователями (создание, редактирование, удаление)
- Управление курсами
- Просмотр статистики системы:
  - Количество пользователей по ролям
  - Общее количество тестов
  - Статистика прохождения тестов
  - Процент успешных попыток

#### 2. Преподаватель
- Создание тестов с вопросами и вариантами ответов
- Редактирование и удаление своих тестов
- Просмотр результатов студентов
- Контроль успеваемости
- Статистика по созданным тестам
- Типы вопросов:
  - Один правильный ответ
  - Несколько правильных ответов

#### 3. Студент
- Прохождение активных тестов
- Просмотр своих результатов
- Статистика успеваемости:
  - Количество пройденных тестов
  - Сданные/не сданные тесты
  - Средний балл
- История попыток по каждому тесту

## Установка и запуск

### Требования
- Docker и Docker Compose
- Порты 3000, 8000, 5432 должны быть свободны

### Быстрый старт с Docker

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd bppk-system
```

2. Запустите приложение:
```bash
docker-compose up --build
```

3. Дождитесь завершения сборки и запуска контейнеров

4. Откройте браузер:
- Frontend: http://localhost:3000
- Backend API: http://localhost:8000
- API документация: http://localhost:8000/docs

## Ручная установка (без Docker)

### Backend

1. Перейдите в папку backend:
```bash
cd backend
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Настройте PostgreSQL и создайте базу данных `bppk_exam`

5. Создайте файл `.env` на основе `.env.example` и укажите параметры подключения к БД

6. Инициализируйте базу данных:
```bash
python -c "from app.db.base import SessionLocal, Base, engine; from app.db.init_db import init_db; Base.metadata.create_all(bind=engine); db = SessionLocal(); init_db(db); db.close()"
```

7. Запустите сервер:
```bash
uvicorn app.main:app --reload
```

### Frontend

1. Перейдите в папку frontend:
```bash
cd frontend
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите приложение:
```bash
npm run dev
```
