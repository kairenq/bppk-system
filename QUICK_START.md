# 🚀 Быстрый старт - Пошаговая инструкция

## Вариант 1: Запуск через Docker (Рекомендуется - самый простой способ)

### Шаг 1: Проверьте установку Docker

Откройте терминал (командную строку) и выполните:

```bash
docker --version
docker-compose --version
```

Если команды не найдены, установите Docker:
- **Windows/Mac**: Скачайте [Docker Desktop](https://www.docker.com/products/docker-desktop)
- **Linux**:
  ```bash
  sudo apt-get update
  sudo apt-get install docker.io docker-compose
  ```

### Шаг 2: Перейдите в папку проекта

```bash
cd /home/user/bppk-system
```

Или если вы на другом компьютере, клонируйте репозиторий:
```bash
git clone <url-репозитория>
cd bppk-system
```

### Шаг 3: Запустите приложение

```bash
docker-compose up --build
```

Этот процесс займет 2-5 минут при первом запуске. Вы увидите много логов - это нормально.

**Дождитесь сообщений:**
- `bppk_backend | Default admin created`
- `bppk_backend | Test users created`
- `bppk_frontend | Local: http://localhost:3000/`

### Шаг 4: Откройте браузер

Когда все запустится, откройте в браузере:

**🌐 Frontend (главное приложение):**
```
http://localhost:3000
```

**📚 API Документация (опционально):**
```
http://localhost:8000/docs
```

### Шаг 5: Войдите в систему

Когда закончите работу, нажмите `Ctrl+C` в терминале, затем:


## Вариант 2: Запуск без Docker (для разработчиков)

Если Docker не подходит, можно запустить вручную:

### Предварительные требования

1. **Python 3.11+**
   ```bash
   python --version
   ```

2. **Node.js 18+**
   ```bash
   node --version
   npm --version
   ```

3. **PostgreSQL**
   - Скачайте и установите PostgreSQL
   - Создайте базу данных `bppk_exam`

### Запуск Backend

#### Шаг 1: Перейдите в папку backend
```bash
cd /home/user/bppk-system/backend
```

#### Шаг 2: Создайте виртуальное окружение
```bash
python -m venv venv
```

#### Шаг 3: Активируйте окружение

**Linux/Mac:**
```bash
source venv/bin/activate
```

**Windows:**
```bash
venv\Scripts\activate
```

#### Шаг 4: Установите зависимости
```bash
pip install -r requirements.txt
```

#### Шаг 5: Настройте подключение к БД

Создайте файл `.env` в папке `backend/`:

```env
POSTGRES_USER=postgres
POSTGRES_PASSWORD=ваш_пароль
POSTGRES_SERVER=localhost
POSTGRES_PORT=5432
POSTGRES_DB=bppk_exam
```

#### Шаг 6: Инициализируйте базу данных
```bash
python init_db.py
```

#### Шаг 7: Запустите сервер
```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Backend запущен на: `http://localhost:8000`

---

### Запуск Frontend

#### Шаг 1: Откройте НОВЫЙ терминал

Не закрывайте терминал с backend!

#### Шаг 2: Перейдите в папку frontend
```bash
cd /home/user/bppk-system/frontend
```

#### Шаг 3: Установите зависимости
```bash
npm install
```

Это может занять несколько минут.

#### Шаг 4: Запустите приложение
```bash
npm run dev
```

Frontend запущен на: `http://localhost:3000`

#### Шаг 5: Откройте браузер
```
http://localhost:3000
```

## 🔧 Решение проблем

### Проблема: Порт уже занят

**Ошибка:** `Port 3000 is already in use` или `Port 8000 is already in use`

**Решение:**
1. Найдите процесс, использующий порт:
   ```bash
   # Linux/Mac
   lsof -i :3000
   lsof -i :8000

   # Windows
   netstat -ano | findstr :3000
   netstat -ano | findstr :8000
   ```

2. Остановите процесс или измените порт:
   - Frontend: в `frontend/vite.config.js` измените `port: 3000` на `port: 3001`
   - Backend: запускайте с другим портом `uvicorn app.main:app --port 8001`

### Проблема: Docker контейнеры не запускаются

**Решение:**
```bash
# Остановите все контейнеры
docker-compose down

# Удалите старые данные
docker-compose down -v

# Пересоберите
docker-compose up --build
```

### Проблема: Ошибка подключения к базе данных

**Для Docker:**
- Подождите 10-15 секунд после запуска
- База данных должна инициализироваться

**Для ручного запуска:**
- Проверьте, что PostgreSQL запущен
- Проверьте правильность данных в `.env`
- Убедитесь, что база данных `bppk_exam` создана

### Проблема: Фронтенд не подключается к API

**Решение:**
1. Убедитесь, что backend запущен на `http://localhost:8000`
2. Проверьте в `frontend/src/services/api.js`:
   ```javascript
   const API_URL = 'http://localhost:8000/api/v1';
   ```
3. Откройте в браузере `http://localhost:8000/docs` - должна открыться документация

### Проблема: CORS ошибки

**Решение:**
В `backend/app/core/config.py` проверьте:
```python
BACKEND_CORS_ORIGINS: list = ["http://localhost:3000", "http://localhost:5173"]
```

Добавьте нужный origin, если используете другой порт.

## 📱 Доступ с другого устройства в локальной сети

Если хотите открыть приложение с телефона или другого компьютера:

1. Узнайте IP-адрес вашего компьютера:
   ```bash
   # Linux/Mac
   ifconfig | grep inet

   # Windows
   ipconfig
   ```

2. Откройте на другом устройстве:
   ```
   http://ваш-ip:3000
   ```

3. Добавьте IP в CORS (в `backend/app/core/config.py`):
   ```python
   BACKEND_CORS_ORIGINS: list = [
       "http://localhost:3000",
       "http://ваш-ip:3000"
   ]
   ```
