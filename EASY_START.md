# 🚀 Быстрый запуск приложения

Простой способ запустить Систему тестирования БППК одной командой!

## 📋 Требования

Перед запуском убедитесь, что у вас установлены:

- **Python 3.8+** - [Скачать](https://www.python.org/downloads/)
- **Node.js 16+** - [Скачать](https://nodejs.org/)
- **npm** (обычно устанавливается вместе с Node.js)

## 🖥️ Запуск на Linux/Mac

1. Откройте терминал в папке проекта
2. Дайте права на выполнение скрипту:
   ```bash
   chmod +x start.sh
   ```
3. Запустите скрипт:
   ```bash
   ./start.sh
   ```

## 🪟 Запуск на Windows

1. Откройте папку проекта в проводнике
2. Дважды кликните на файл **`start.bat`**
3. Или откройте командную строку и выполните:
   ```cmd
   start.bat
   ```

## ✨ Что делает скрипт?

Скрипт автоматически выполняет следующие действия:

1. ✅ Проверяет наличие Python, Node.js и npm
2. 📦 Устанавливает все зависимости для Backend (Python)
3. 📦 Устанавливает все зависимости для Frontend (React)
4. 🗄️ Создает и инициализирует базу данных SQLite
5. 👥 Создает тестовых пользователей
6. 🚀 Запускает Backend на `http://localhost:8000`
7. 🌐 Запускает Frontend на `http://localhost:5173`

## ❓ Возможные проблемы

### Порты уже заняты

Если порты 8000 или 5173 заняты другими приложениями:

**Linux/Mac:**
```bash
# Найти и остановить процесс на порту 8000
sudo lsof -ti:8000 | xargs kill -9

# Найти и остановить процесс на порту 5173
sudo lsof -ti:5173 | xargs kill -9
```

**Windows:**
```cmd
# Найти процесс на порту 8000
netstat -ano | findstr :8000

# Остановить процесс (замените PID на номер из предыдущей команды)
taskkill /PID <PID> /F
```

### Python не найден (Windows)

Убедитесь, что Python добавлен в PATH при установке. Перезапустите компьютер после установки Python.

### npm install выдает ошибки

Попробуйте очистить кеш npm:
```bash
npm cache clean --force
cd frontend
rm -rf node_modules package-lock.json
npm install
```
